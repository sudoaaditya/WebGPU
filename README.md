# WebGPU

A collection of small WebGPU learning projects and experiments, built from scratch using the native `navigator.gpu` API (no frameworks).

Each project lives in its own numbered folder and is a self-contained HTML/JS pair that can be opened directly in a WebGPU-enabled browser.

## Requirements

- A browser with WebGPU support (recent Chrome/Edge, or Firefox/Safari with WebGPU enabled)
- No build step or dependencies — just open the project's `.html` file

## Projects

| # | Project | Description |
|---|---------|-------------|
| 01 | [BlueScreen](01-BlueScreen) | Initializes the WebGPU device/context and clears the canvas to a solid blue color every frame. Includes fullscreen toggle (`F`) and exit (`Esc`). |
